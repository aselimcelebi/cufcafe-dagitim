# cufcafe-dagitim

CufCafe Pro **kararlı kanalı** dağıtım deposu.

Bu depoda kaynak kod yoktur. Sadece imzalı `manifest.json`, imzalı lisans dosyaları (`lisanslar/`) bulunur;
güncelleme paketleri bu deponun **Releases** bölümündedir.

Dosyalar Ed25519 ile imzalıdır. İmzası tutmayan dosyayı CufCafe Pro sunucusu kabul etmez.
